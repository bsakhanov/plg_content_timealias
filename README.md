# Timealias — алиасы-метки времени для материалов Joomla

Плагин группы `content` для Joomla 6. Каждому новому материалу он присваивает алиас вида `ГГГГММДД-ЧЧММСС` — например, `20261006-053650`. Адреса статей получаются короткими, одинаковыми по форме и не зависят от заголовка: его можно сколько угодно править после публикации, ссылка останется прежней.

*A Joomla 6 content plugin that gives every new article a timestamp alias (`YYYYMMDD-HHMMSS`) in the site time zone, with `-2`, `-3` suffixes on collisions.*

## Как работает

- Срабатывает только при создании материала. Правка существующей статьи алиас не меняет; «Сохранить как копию» создаёт новый материал и получает новый алиас.
- Время берётся по часовому поясу сайта (*Общие настройки → Сервер → Часовой пояс сайта*), а не по часам сервера, которые обычно идут по UTC.
- Ядро Joomla требует, чтобы алиас был уникален в пределах категории, и отказывается сохранять материал при совпадении. Поэтому, если две статьи созданы в одну секунду в одной категории, вторая получит `-2`, третья — `-3`. Учитываются и материалы в корзине.
- Обрабатываются материалы из админки, через REST API и через форму на сайте. Категории, пункты меню и материалы других компонентов не затрагиваются.
- Алиас, вписанный вручную или пришедший при импорте, по умолчанию сохраняется: метка времени ставится, только когда поле оставлено пустым. Если нужна метка для любого нового материала, в настройках плагина выключите «Сохранять заданный алиас».

## Импорт старых статей

Статьи, которые уже лежат на сайте, плагин не трогает: правку существующего материала он пропускает.

При импорте всё зависит от того, как импортёр сохраняет статьи:

- **Через модель Joomla или REST API** — плагин видит их как новые. Если импортёр передаёт старый алиас, он сохраняется, и прежние адреса статей не ломаются. Если алиаса нет, ставится метка времени.
- **Прямой записью в базу** (SQL-дамп, запись в таблицу в обход модели) — плагин вообще не вызывается, алиасы остаются как были.

Самый осторожный путь для большой миграции — выключить плагин на время импорта и включить после.

Ядро Joomla при сохранении из формы и через API само подставляет транслит заголовка в пустое поле алиаса — раньше, чем срабатывает плагин. Поэтому, чтобы отличить пустое поле от заполненного, плагин смотрит на исходный запрос: поле `jform[alias]` формы, тело запроса API или данные, переданные модели напрямую.

## Установка

1. Скачайте `plg_content_timealias_<версия>.zip` из [Releases](https://github.com/bsakhanov/plg_content_timealias/releases).
2. *Система → Установка → Расширения*, загрузите архив.
3. Включите плагин «Материалы — Timealias» в *Система → Плагины*.

## Требования

Joomla 6.x, PHP 8.3+. Проверено на Joomla 6.1.4.

## Сборка

```bash
./build.sh   # → dist/plg_content_timealias_<версия>.zip
```

Версия берётся из `timealias.xml`.
